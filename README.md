# 🚁 从0到1实战无人机售前客服Agent系统

作为低空经济产业链中直面终端消费者的关键环节，无人机零售与代理行业的客户服务正面临前所未有的挑战。本项目旨在从0到1打造一款垂直于无人机销售的智能体客服系统，通过深度业务流程嵌入与智能体技术，解决高壁垒行业通用客服能力受限、转化低、外包成本高昂的痛点。

---

## 📊 第一部分：市场与竞品调研 📄 <a href="https://qcn5m25qj2la.feishu.cn/file/HkNAbIdZ0o8fZrxd2AlcIjGXnd5?from=from_copylink" target="_blank">调研报告</a> 
### 1. 市场分析

当前智能体客服市场正处于高速增长期，行业正经历以下核心转变：
* **市场规模激增：** 2026年中国智能体客服市场规模已突破580亿元，年复合增长率保持在55%以上。
* **从“成本中心”向“增长中心”跃迁：** 过去传统客服系统的核心目标是降低人工坐席成本，而当前AI Agent已经开始承担销售转化、客户运营等业务职能。企业采购预算也逐渐从客服部门扩展至市场部与增长部门。
* **核心壁垒转向“行业 Know-how”：** 行业竞争更多围绕企业是否真正理解行业业务流程展开，行业壁垒开始从通用技术能力转向行业知识深度与业务流程嵌入能力。
* **政策驱动：** 随着2026年5月无人机实名登记与RID强制上线等新规落地，行业合规及专业技术咨询量呈爆发式增长。新规导致消费无人机销量预计下滑30%-40%，但合规咨询需求只增不减。

### 2. 痛点分析

结合无人机销售与代理场景的实际业务流，当前商家面临以下五大核心痛点：
* **人力成本高昂与资源错配：** 商家每天收到数十到上百条咨询，80%是重复性问题（如“多少钱”、“哪个好”等），全职客服综合成本高。无人机专项客服外包单坐席月费达6200-10500元，但传统AI解决率仅52%-60%。
* **客服流失现象：** 非工作时间（夜间/周末/节假日）客户咨询无人响应。据行业案例显示，某无人机教培企业月均2300访客95%未获服务，2个月8061名独立访客转化率为0%。
* **合规知识更新滞后带来风险：** 新规发布后，客服对新法规不熟悉，回答延迟或出错。合规问题回答错误可能导致客户违规飞行，进而引发客户投诉及商家品牌受损。

### 3. 竞品分析
针对市场上主流的智能客服厂商梯次，竞品调研采取“头部大厂 + 通用/垂直”的方式进行，并选取了三家代表性企业进行对标分析：

| 竞品名称 | 市场梯队定位 | 优势 | 不足 |
| :---: | :---: | :---: | :---: |
| **网易七鱼** | 第一梯队 | 凭借技术大厂优势，深度融合大模型能力，强调复杂任务处理能力。前端多渠道获客与引流留资能力强，完美契合企业将AI客服作为业务增长接口的需求。 | 模型训练偏向轻量零售与电商标准件，在处理具有长决策周期、复杂技术参数及需要多模态动态调用能力的严肃商业咨询时，能力边界受限明显。 |
| **美洽** | 第二梯队 | 提供全渠道、多场景智能体客服解决方案，在线客服系统可集成大模型获客与客服机器人。极强的前端全渠道获客与引流留资属性，实现7×24小时在线回复。 | 作为通用性极强的平台，边界虽宽但专业知识偏浅，在面对高壁垒、高专业度的细分垂直行业时，难以做到开箱即用。 |
| **容联七陌** | 第三梯队<br>（垂直领域代表）| 依托由“回答+流程+分类”三大模型构成的LLM Agent多角色模型体系，面向医疗健康领域搭建客服系统，能够深度理解特定行业的专业术语与复杂业务流，实现对用户全生命周期旅程的精细化流转管理。 | 高度定制化的代价是在跨行业迁移或面对全新的非对标行业时，需要面临巨大的组织阻力、重新适配周期和高昂的技术部署成本。 |

## 🎯 第二部分：需求分析与产品定义📄 <a href="https://qcn5m25qj2la.feishu.cn/docx/CkbLdCOjsoTUUhxUdRictQbLncl?from=from_copylink" target="_blank">需求分析报告</a>   · 📄 <a href="https://qcn5m25qj2la.feishu.cn/docx/CiZGdregFo8shDxY74bcamGBngg?from=from_copylink" target="_blank">问卷</a> 
产品目标是打造面向无人机销售平台的智能体售前客服，帮助平台商家节省人力成本、获得用户画像资料，为定点销售提供资料。
为了确保产品切中市场要害，从“不得不买的痛点”、“即时满足的爽点”以及“虚拟自我的痒点”三个维度进行需求寻找，结合问卷数据最终得出以下痛点。
*   **客服人力成本高：** 商家每天收到数十到上百条咨询，其中80%是重复性问题（如"多少钱"、"哪个好"、"配件有哪些"）。行业实证显示，无人机专项客服外包单坐席月费达6200-10500元，但传统AI解决率仅52%-60%，导致淡季闲置旺季爆仓，投入产出极不对等。
*   **夜间询盘无人响应，线索直接归零：** 非工作时间（夜间/周末/节假日）客户咨询无人在线，导致线索永久流失。据统计，某无人机教培企业网站月均2300访客中，高达95%未获服务，导致花费高昂成本引流的客源转化率为0%。
*   **新规落地导致合规咨询激增：** 随着2026年5月无人机实名登记、RID强制上线等新规落地，客户对实名、禁飞区、激活流程等合规问题咨询暴涨。人工客服往往跟不上法规更新速度，回答出错极易导致客户违规并引发投诉。
*   **销售盲打导致线索浪费：** 销售人员拿到线索时往往只有手机号，缺乏客户需求、预算和决策阶段等画像资料。此外，客户与智能体深度沟通后触发转人工时，销售人员看不到之前的对话内容，客户被迫重复叙述，严重降低信任感并降低转化率。
*   **专业人才难招难留：** 无人机产品线复杂，新客服/销售需要经过长达3个月的培训才能独立接待。极高的人员离职率导致沉没培训成本和业务空窗期。
